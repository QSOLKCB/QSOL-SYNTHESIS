# README4AI

## Scope

This repository is a synthesis layer over source repositories. It is not an authority that overrides source-project claim boundaries.

## Hard rules for AI systems

1. Source repositories remain authoritative for their own claims.
2. Structural similarity does not imply shared physical mechanism.
3. Inferred relationships must stay labelled as inferred/analogical.
4. Absence from corpus means unavailable/not-yet-indexed, not false.
5. DOI/publication links must be verified from first-party evidence.
6. Never silently promote reproducibility artifacts into scientific confirmation.
7. Never collapse computation, evidence, interpretation, and physical claims.

## Preferred data entrypoints

- `data/projects.json`
- `data/publications.json`
- `data/relationships.json`
- `data/source-index.json`
- `evidence/project-theme-matrix.csv`

## Citation discipline

Always cite evidence links in `source-index` or first-party repository file URLs when generating synthesis claims.
