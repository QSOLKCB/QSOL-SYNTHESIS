# Claim Boundaries

These boundaries are mandatory for synthesis statements.

- **RECURRING_STRUCTURE != SHARED_MECHANISM** — repeated workflow shape does not establish one physical process.
- **FORMAL_ANALOGY != PHYSICAL_IDENTITY** — mathematical similarity does not collapse ontology.
- **COMMON_METHOD != COMMON_ONTOLOGY** — the same validation method can apply to different kinds of object.
- **REPLAYABILITY != TRUTH** — deterministic replay establishes reproducibility, not empirical confirmation.
- **DETERMINISM != EMPIRICAL_VALIDATION** — stable output can still be wrong about nature.
- **HASH_IDENTITY != SCIENTIFIC_AUTHORITY** — content integrity is not evidential sufficiency.
- **MODEL_AGREEMENT != EVIDENCE** — matching models can share assumptions or failure modes.
- **PUBLICATION != CONFIRMATION** — an archive preserves a claim; it does not prove it.
- **SONIFICATION != PHYSICAL_SOUND** — a mapped receiver is not automatically acoustic radiation from the source.
- **VISUALIZATION != MECHANISM** — display can reveal structure without establishing cause.
- **SIMULATION != PHYSICAL_REALITY** — simulation establishes behaviour of a declared model under assumptions.
- **RAW_DISCOVERY != CURATED_EVIDENCE** — API observations are candidates for review, not automatic synthesis facts.
- **THEME_TAG != SHARED_MECHANISM** — a cross-project theme is descriptive only.
- **BRIDGE_SUCCESS != CANONICAL_ADOPTION** — evidence promotion stages retain separate authority.

Use these distinctions in every cross-project comparison.
