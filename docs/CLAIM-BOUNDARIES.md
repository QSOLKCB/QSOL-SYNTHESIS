# Claim boundaries

These boundaries are mandatory for synthesis statements in this repository.

- **RECURRING_STRUCTURE != SHARED_MECHANISM**: repeated workflow shape across projects does not establish one physical process.
- **FORMAL_ANALOGY != PHYSICAL_IDENTITY**: mathematical similarity can be exact while ontology differs.
- **COMMON_METHOD != COMMON_ONTOLOGY**: similar methods can test different things.
- **REPLAYABILITY != TRUTH**: deterministic replay establishes reproducibility, not empirical confirmation.
- **DETERMINISM != EMPIRICAL_VALIDATION**: stable output can still be wrong about nature.
- **HASH_IDENTITY != SCIENTIFIC_AUTHORITY**: content integrity is not evidential sufficiency.
- **MODEL_AGREEMENT != EVIDENCE**: matching models can share assumptions and errors.
- **PUBLICATION != CONFIRMATION**: publication archives claims; it does not prove them.
- **SONIFICATION != PHYSICAL_SOUND**: rendered mappings are representations unless explicitly measured physical audio.
- **VISUALIZATION != MECHANISM**: plots expose patterns, not causal proof.
- **SIMULATION != PHYSICAL_REALITY**: simulation validates model behavior under assumptions.

Use these distinctions in every cross-project comparison.
