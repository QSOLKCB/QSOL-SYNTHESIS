# Counterexamples and Limitations

A synthesis becomes unhelpful if every project is forced into it. Several limits are therefore explicit.

## Not every project implements the full pipeline

Creative, historical, infrastructure and experimental repositories emphasize different stages. Some have rich replay and provenance; others mainly expose a representation or hypothesis. Representative contrasting sources include `src:qai-uft:readme`, `src:uff:readme`, `src:qsol-substrate:readme`, and `src:rivet:readme`. Absence of a stage is not a defect unless the project claims that stage.

## Shared vocabulary can be accidental

Terms such as state, information, geometry, resonance, observation and recovery are common across many disciplines. A relationship edge is included only when first-party documentation supports a meaningful methodological, historical, implementation or evidence connection.

## First-party sources have a bias

This baseline synthesizes how the programme describes and structures itself. It does not independently validate the external scientific literature behind every project. Publication and source metadata establish provenance, not peer-reviewed truth.

## Public-only scope is incomplete

Private repositories are intentionally excluded from the public baseline. The organisation also changes over time. Counts and selections are snapshots.

## Theme tags are coarse

A theme marked documented means the indexed source supports it. A not-found cell is not evidence that the theme is absent elsewhere in the repository.

## Methodological evolution is not a ladder of quality

Older exploratory work should not be rewritten to resemble later evidence discipline. The contrast is grounded, for example, in `src:qai-uft:readme` versus later evidence-bound sources such as `src:uft-id-3-0:readme` and `src:uff:readme`. The evolution section records a change in emphasis, not a score.

## The central thesis can fail

If deeper reading shows that “trustworthy transformation” is too broad to discriminate QSOL-IMC from ordinary good engineering, the thesis should be narrowed. Useful counterexamples include projects whose main purpose is generative/creative rather than preservation, projects where no oracle exists, and relationships driven only by later infrastructure reuse.

These limitations are not peripheral; they are necessary tests of whether the synthesis explains rather than merely redescribes the corpus.
